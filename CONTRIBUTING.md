# Contributing to Oriw

Thank you for helping build Oriw.

## Before you start

- Check open issues first, and comment on one before starting larger work so we can agree on the approach.
- Read the [product principles](https://github.com/oriw-app/oriw#product-principles): every change should keep Oriw fast, light, private, accessible and fair.

## Contributor License Agreement

Before we can merge your first pull request, you'll be asked to sign our Contributor License Agreement (CLA). It lets the project offer Oriw under both its open-source license and commercial terms, which funds development. A bot will guide you on your first pull request.

## Pull requests

1. Fork the repo and create a branch from `main`.
2. Keep each pull request focused on one change.
3. Add or update tests, and make sure all checks pass.
4. Describe what changed and why, with screenshots for UI changes.

## Reporting bugs and ideas

Use the issue templates for bug reports and feature ideas. For security problems, do not open an issue; see SECURITY.md.
